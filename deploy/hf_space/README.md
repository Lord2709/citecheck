# CiteCheck

Course project (UMD DATA/MSML 641). Paste a draft with citations and CiteCheck finds each cited sentence, looks up the
reference, reads the paper (and the open-access full text when unsure) and shows whether it supports the sentence, with
the deciding sentences. It can also find papers for a research direction.

Source code, evaluation and limits: https://github.com/Lord2709/citecheck
